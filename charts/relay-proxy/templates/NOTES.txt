2. Flag definitions come from {{ .Values.flags.dir }}/ inside the chart, served through the
   ConfigMap "{{ include "relay-proxy.flagsConfigMapName" . }}" mounted at {{ .Values.flags.mountPath }}:

{{ range $path, $_ := .Files.Glob (include "relay-proxy.flagsGlob" .) }}     {{ $.Values.flags.mountPath }}/{{ base $path }}
{{ end }}
   Flip one live, without restarting anything:

     kubectl edit configmap {{ include "relay-proxy.flagsConfigMapName" . }} --namespace {{ .Release.Namespace }}

   Allow roughly a minute: the kubelet refreshes the mount on its own sync
   period, then the relay proxy re-reads it within its pollingInterval.

   Such an edit lasts until the next upgrade, which needs --force-conflicts to
   reclaim the field it took over:

     helm upgrade {{ .Release.Name }} <chart> --force-conflicts
{{- end }}
